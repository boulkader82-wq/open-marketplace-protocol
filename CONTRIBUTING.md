# Contributing to Open Marketplace Protocol

Thank you for your interest in contributing to Open Marketplace Protocol.

## Project Principles

- Open-source from day one.
- Non-custodial architecture.
- Security and correctness come first.
- Smart contracts are the source of truth for on-chain state.
- Changes should be modular and maintainable.
- Privacy and user ownership should be respected.

## Before Contributing

Please read:

- README.md
- ARCHITECTURE.md
- ROADMAP.md
- SECURITY.md

Before making changes, understand the current architecture and the project's roadmap.

## Contributions

Contributions may include:

- Smart contract development
- Protocol development
- Frontend development
- SDK development
- Indexer development
- Decentralized storage integration
- Testing
- Documentation
- Security improvements

## Pull Requests

Please keep pull requests:

- Focused on one purpose.
- Small and reviewable where possible.
- Clearly described.
- Accompanied by tests when applicable.

Do not introduce breaking architectural changes without prior discussion.

## Security

Do not publicly disclose security vulnerabilities through ordinary issues or pull requests.

For security-related concerns, follow the instructions in SECURITY.md.

## Development Direction

The project is developed incrementally.

Do not assume that future roadmap features are already implemented. Check the current repository state and ROADMAP.md before contributing.
